## 实现期追加决策

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-11-03 | 统计口径采用 **04:00 换日**（`dayStartHour=4`），与预算周期一致 | 避免"跨午夜周期被自然日切碎导致重复计数"；参考产品同样把 04:00 使用日作为一等公民 |
| 2026-11-03 | 未知模型 → 成本 `null`，不使用兜底价估算 | 参考产品语义：未知价格不猜；避免"看起来像账单"的假数字 |
| 2026-11-03 | 插件只注册服务端路由，不做客户端注入 | DSH 客户端 API 处于 rc 阶段（PRD R2），薄封装降低断裂面 |
| 2026-11-03 | 默认预算 2,000,000 tokens，并在 UI/CLI 提示"使用默认值" | 首次运行必须可用；不假设用户体量，明确提示按实际调整 |
