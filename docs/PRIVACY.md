# 隐私与数据边界（PRIVACY）

## 1. 数据分级与处理

| 数据 | 分级 | 是否采集 | 存储位置 | 是否外传 |
|---|---|---|---|---|
| usage 数字（token 桶） | L1 | ✅ | `~/.dsh-cockpit/state.json` 派生摘要 | ❌ |
| 时间戳 / turn / step | L1 | ✅ | 同上（聚合） | ❌ |
| 模型 / provider | L1 | ✅ | 同上 | ❌ |
| 工具名（tool/call） | L1 | ✅ | 同上（计数） | ❌ |
| 会话标题 | L2（可能含项目/客户名） | ✅（可打码） | 同上 | ❌ |
| 工作区路径（cwd） | L2 | ✅（仅末段 slug） | 同上 | ❌ |
| 对话正文 / 工具参数 | L3 | ❌ **不读取** | — | ❌ |
| API Key / 登录凭据 | L4 | ❌ 不读取（余额模式仅读环境变量，不落盘） | — | ❌ |

## 2. 采集范围（精确到文件）

- 只读：`~/.dsh/sessions/**/session.v{3,4}.jsonl[.zstd]`
- 只写：`~/.dsh-cockpit/`（`config.json` / `state.json` / `comfort.json` / `metrics.jsonl`）
- **绝不写** `~/.dsh/**`；测试中有只读断言守护。

## 3. 网络

| 场景 | 是否联网 | 说明 |
|---|---|---|
| 默认（本地模式） | ❌ | 完全离线 |
| 官方余额（可选，显式开启） | ✅ | `GET https://api.deepseek.com/user/balance`；仅为对账请求余额，**不发送任何本地数据**（无会话/标题/路径）；Key 只从环境变量读取、不落盘、不日志、错误信息不含 Key；快照仅存金额与时间（`balance.json`，尽力 0600） |
| 团队同步（可选，默认关闭） | ✅ | 仅在显式配置 endpoint/token 后推送聚合快照（见 `docs/SYNC.md`） |
| 遥测 | ❌ | 无任何上报端点 |

实时语义：打开仪表盘或点「刷新」会立即取一次最新余额（手动刷新绕过 15s TTL 缓存）；自动轮询走 TTL 防抖。无 Key / 401 / 402 / 超时 / 网络错误只影响余额展示，不阻塞其它数据。

## 4. 本地事件日志

`~/.dsh-cockpit/metrics.jsonl`：仅记录扫描耗时、会话数、状态延迟等**聚合指标**，用于自测与排障；
默认开启，可在配置中关闭（`metrics.enabled=false`），可随时删除。

## 5. 你能做的控制

| 目的 | 操作 |
|---|---|
| 隐藏项目/客户名 | 设置 `ui.maskTitles=true`（Web 设置抽屉 / `config --set ui.maskTitles=true`） |
| 关闭本地日志 | `config --set metrics.enabled=false` |
| 完全删除本地数据 | 删除 `~/.dsh-cockpit` 目录（不影响 DSH） |
| 不使用余额模式 | 不设置 `DEEPSEEK_API_KEY`，或把 `budget.axis` 设回 `budget` |

## 6. 与参考产品一致的诚实声明

- 本工具**不是**安全审计过的生产级产品，是本地只读观测器；
- 金额是估算；压缩预测是启发式；均不构成官方数据；
- 若你在共享机器/多人环境使用，请自行评估"标题可见性"风险（建议开打码）。
